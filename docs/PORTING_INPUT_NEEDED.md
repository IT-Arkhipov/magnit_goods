# Требования к данным для портирования под «Магнит Косметик»

> Чек-лист информации, которую **нельзя получить из кода** — только перехватом
> реальных запросов сайта. Заполните значения ниже — после этого портирование
> по `docs/PORTING.md` (Сценарий Б) станет полностью механическим.
>
> **Как собирать:** открыть magnit.ru в браузере, выбрать магазин «Магнит Косметик»,
> DevTools (F12) → вкладка Network, фильтр `goods/search`. Выполнить действия
> на сайте (открыть каталог, категорию, товар) и скопировать нужные данные.

---

## 1. `catalogType` 🔴 (критично)

Захардкожен как `"1"` в трёх файлах:
- `src/server/services/magnit_api.py` → `MagnitAPIClient.search()`
- `src/server/services/catalog_scanner.py` → `_fetch_category_data()`
- `src/server/services/catalog_updater.py` → `fetch_category_data()`

Если у Косметика другое значение — API вернёт пустые категории/товары.

```
catalogType для Косметика: (заполнить)
```

Откуда взять: payload запроса `POST /webgate/v2/goods/search` на сайте
с выбранным магазином Косметик → поле `catalogType`.

---

## 2. Формат URL товара 🔴 (критично)

Захардкожен в `src/server/templates/products.html` (3 места):

```
https://magnit.ru/product/{product_id}-{seoCode}?shopCode={storeCode}&shopType={shop_type}
```

Проверить, что для Косметика путь и параметры такие же.

```
Пример реального URL товара Косметика: (заполнить)
Совпадает ли шаблон: да / нет
Если нет — правильный шаблон: (заполнить)
```

---

## 3. Пример ответа API для `storeType=DG` 🟠

Один ручной POST (Swagger `/docs` или curl) с кодом реального магазина
Косметик и `storeType=DG`. Нужны для проверки парсинга:

```
store_code использованный магазин: (заполнить)

a) Категории (запрос БЕЗ categories[]):
   - есть ли fastCategoriesExtended: да/нет
   - пример одной категории (id, title): (заполнить)

b) Товары (запрос с categories=[<id из п.a>]):
   - пример одного item (полностью JSON): (заполнить)
   - цена в копейках или рублях: (заполнить)

c) Магазины (POST /webgate/v1/stores-facade/search/detail,
   storeTypeListV2=["DG"]):
   - есть ли externalId.storeCode в ответе: да/нет
   - пример одного магазина (JSON): (заполнить)
```
