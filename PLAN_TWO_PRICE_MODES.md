# План: Два режима отображения изменения цен

## Цель
Добавить чекбокс "Новая цена" для переключения между двумя режимами отображения изменения цен:
1. **Режим "Новая цена"** (чекбокс включён, по умолчанию): показывать изменение от предыдущего сканирования
2. **Режим "Последнее изменение"** (чекбокс выключен): показывать последнее реальное изменение цены

## Реализация

### Бэкенд

#### 1. models.py
Добавлены два новых поля в класс `Product`:
- `last_change_price` — цена до последнего изменения
- `last_change_date` — дата последнего изменения цены

#### 2. catalog_scanner.py
Обновлена логика сканирования:
- **UPDATE**: всегда обновляем `previous_price` (цена при предыдущем сканировании)
- **UPDATE**: при изменении цены также обновляем `last_change_price` и `last_change_date`
- **INSERT**: устанавливаем `previous_price = current_price` (та же цена, нет изменения)

#### 3. database.py
Добавлена функция миграции `migrate_add_last_change_fields()`:
- Добавляет колонки `last_change_price` и `last_change_date`
- Заполняет их для существующих товаров с изменением цены
- Вызывается из `init_db()`

#### 4. routes/catalog.py
Обновлены три API endpoint'а:
- `GET /api/products` — добавлены `last_change_price`, `last_change_date`
- `GET /api/products/{product_id}` — добавлены новые поля
- Поля возвращаются в JSON ответе

### Фронтенд

#### 1. templates/products.html
- Добавлен чекбокс "Новая цена" в фильтры (с отступом справа)
- Добавлены глобальные переменные и функции:
  - `showNewPriceMode` — текущий режим
  - `loadPriceModeState()` — загрузка состояния из localStorage
  - `togglePriceMode()` — переключение режима
  - `formatDate()` — форматирование даты
- Обновлена функция `renderProductRow()`:
  - Вычисляет `changePercent`, `previousPrice`, `changeDate` в зависимости от режима
  - Режим 1: использует `price_change_percent`, `previous_price`, `last_price_change`
  - Режим 2: вычисляет процент от `last_change_price`, использует `last_change_date`
  - Тултип показывает остаток и дату обновления (режим 1) или дату изменения (режим 2)
- Обновлена функция `compareInStores()` для использования двух режимов
- Добавлен вызов `loadPriceModeState()` в DOMContentLoaded

#### 2. templates/_products.html
- Аналогичные изменения как в products.html
- Добавлен чекбокс в фильтры
- Добавлены функции режима цен
- Обновлена таблица рендеринга товаров с использованием двух режимов
- Обновлена функция `compareInStores()`
- Добавлен вызов `loadPriceModeState()` в DOMContentLoaded

#### 3. templates/catalog.html
- После завершения сканирования устанавливается `localStorage.setItem('showNewPriceMode', 'true')`
- Это автоматически включает чекбокс при перезагрузке страницы /products

## Логика работы

### Режим 1: "Новая цена" (включён)
- Показывает изменение от предыдущего сканирования
- Использует `price_change_percent` и `previous_price`
- Тултип: остаток + дата последнего сканирования

### Режим 2: "Последнее изменение" (выключен)
- Показывает последнее реальное изменение цены
- Вычисляет процент от `last_change_price`
- Тултип: предыдущая цена + дата изменения + остаток (если есть изменение)

### Сохранение состояния
- Состояние чекбокса сохраняется в localStorage
- После сканирования флаг автоматически устанавливается в `true`
- При перезагрузке страницы состояние восстанавливается

## Примеры

### Сценарий 1: Первое сканирование (100₽)
```
price = 100
previous_price = 100
price_change_percent = NULL
last_change_price = NULL
```
Оба режима: `100₽` (без процента)

### Сценарий 2: Цена изменилась (100₽ → 120₽)
```
price = 120
previous_price = 100
price_change_percent = -20
last_change_price = 100
last_change_date = 2026-05-31 14:20
```
- Режим 1: `120₽ (↑20%)` — тултип: остаток, дата сканирования
- Режим 2: `120₽ (↑20%)` — тултип: предыдущая цена 100₽, дата изменения

### Сценарий 3: Цена не изменилась (120₽ → 120₽)
```
price = 120
previous_price = 120
price_change_percent = -20 (не обновлено)
last_change_price = 100 (не обновлено)
```
- Режим 1: `120₽` (без процента) — тултип: остаток, дата сканирования
- Режим 2: `120₽ (↑20%)` — тултип: предыдущая цена 100₽, дата изменения
