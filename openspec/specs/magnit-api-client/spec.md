# magnit-api-client Specification

## Purpose
Определяет единые правила обращения сервера к API каталога Магнита: в каком формате передаётся тип магазина, какие значения используются по умолчанию и как ограничивается частота запросов, чтобы избежать блокировки.

## Requirements

### Requirement: Тип магазина передаётся в едином формате
Каждый запрос к API каталога Магнита (товары и подкатегории) SHALL передавать тип магазина как числовой код типа. Входное значение может быть API-кодом (`MM`, `MM_MINI`, `ME`, ...), русским названием (`Магнит`, `Мини`, ...) или числовым кодом; все три SHALL приводиться к одному и тому же числовому коду.

#### Scenario: Русское название
- **WHEN** сканирование выполняется для магазина с типом `Экстра`
- **THEN** и запрос товаров, и запрос подкатегорий передают `storeType` = `6`

#### Scenario: API-код из .env
- **WHEN** `STORE_TYPE=MM_MINI`, и запускается полная замена каталога
- **THEN** запросы передают `storeType` = `2`

### Requirement: Единое значение типа по умолчанию
Если тип магазина не удаётся определить ни из записи магазина, ни из конфигурации, система SHALL использовать одно и то же значение по умолчанию (тип «Магнит») во всех операциях и SHALL NOT подставлять захардкоженный код магазина.

#### Scenario: Замена каталога без настроек
- **WHEN** `STORE_CODE` и `STORE_TYPE` не заданы, и в БД есть активный магазин типа `Мини`
- **THEN** замена каталога выполняется с кодом этого магазина и его типом `Мини`

#### Scenario: Нет ни настроек, ни магазинов
- **WHEN** `STORE_CODE` не задан, и в БД нет активных магазинов
- **THEN** замена каталога завершается ошибкой «не выбран магазин», и запросы к API не отправляются

### Requirement: Ограничение частоты запросов к каталогу
Каждый запрос сервера к API каталога Магнита SHALL выполняться не чаще, чем через 0.5 секунды плюс случайная пауза 0.1–0.5 секунды после предыдущего запроса того же клиента, включая запросы подкатегорий при синхронизации.

#### Scenario: Синхронизация подкатегорий
- **WHEN** синхронизация подкатегорий обрабатывает подряд несколько корневых категорий
- **THEN** интервал между соседними запросами к API не меньше 0.6 секунды
