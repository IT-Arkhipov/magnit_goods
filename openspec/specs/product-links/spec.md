# product-links Specification

## Purpose
Определяет переход пользователя к странице товара на сайте Магнита: прямая ссылка с кодом и типом магазина показанной цены.

## Requirements

### Requirement: Ссылка на товар открывает магазин показанной цены
Ссылка на страницу товара на сайте Магнита со страницы `/products` SHALL передавать код и числовой тип того магазина, чья цена показана в ячейке: `shopCode` — код магазина, `shopType` и cookie `x_shop_type` — код типа записи этого товара. `shop_type` в ответе `GET /api/products/multi-prices` SHALL равняться коду типа записи товара.

#### Scenario: Ссылка для магазина «Моя цена»
- **WHEN** пользователь нажимает на цену товара в колонке магазина 210117 («Моя цена»)
- **THEN** ссылка содержит `shopCode=210117&shopType=9`, а не `shopType=3`

#### Scenario: Два магазина с одним кодом
- **WHEN** в сравнении есть колонки (`100`, `Магнит`) и (`100`, `Экстра`), и пользователь нажимает на цену в колонке «Экстра»
- **THEN** ссылка содержит `shopCode=100&shopType=6`
