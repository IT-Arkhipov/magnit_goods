# Design

## Context

`src/server/routes/stores.py` импортирует `Request` (строка 1, `from fastapi import ... Request`) и `time` (строка 7, `import time`). Оба имени не встречаются больше нигде в модуле: `grep -nE "\b(Request|time)\b"` возвращает только строки импорта, а `ruff check --select F401` подтверждает `fastapi.Request` и `time` как unused. Мотивация — в proposal.md (§ Why).

Ограничения: модуль загружается как часть приложения FastAPI; любое изменение импортов должно сохранять работоспособность импорта `src.server.app`.

## Goals / Non-Goals

**Goals:**
- Точечно удалить два неиспользуемых импорта, не затронув соседние имена и логику.
- Оставить модуль компилируемым и загружаемым приложением.

**Non-Goals:**
- Рефакторинг остальных импортов или стиля модуля.
- Исправление других lint-предупреждений, кроме `Request`/`time`.

## Decisions

**1. Ручное редактирование вместо `ruff --fix`.**
F401 для обоих импортов помечен `[*]` (автофиксируемый), но `ruff --fix` применит фиксы ко всем правилам/строкам файла сразу, выходя за границы изменения. Альтернатива — `ruff check --select F401 --fix` (только F401, только unused imports): безопаснее широкого `--fix`, но всё равно меняет файл целиком, если появятся другие F401. Выбираем точечный ручной edit: минимальный диф, полный контроль.

**2. `Request`: удалить имя из строки 1, `time`: удалить строку 7 целиком.**
Строка 1 содержит несколько имён (`APIRouter, Depends, HTTPException, Query, Request`) — удаляем только `, Request`, сохраняя остальные. Строка 7 содержит только `import time` — удаляем строку полностью. Альтернатива (`ruff --fix`) даёт тот же результат, но без контроля над дифом.

## Risks / Trade-offs

- [Номера строк в tasks (10/12) расходятся с фактическими (1/7)] → сверять не по номеру строки, а по контексту: `Request` — последнее имя в `from fastapi import ...`; `time` — отдельная строка `import time`. Границы правки задаёт контекст, не индекс строки.
- [Ложное срабатывание F401, если имя используется в докстринге/комментарии] → `grep -nE` с `\b` вернул только строки импорта; использование в тексте исключено.
- [Удаление `time` сломает отложенный вызов в helper] → в модуле нет отложенного/`time.sleep`-кода; grep подтвердил отсутствие обращений.

## Migration Plan

Миграция не требуется: изменение не затрагивает данные, API или контракты. Деплой = обычный коммит. Rollback = `git revert` коммита (или восстановление двух строк импорта).
