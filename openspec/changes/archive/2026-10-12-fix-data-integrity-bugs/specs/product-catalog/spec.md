# Spec Delta

## Purpose

Определяет, какие товары и в каком виде отдаёт API списка товаров: фильтрацию по магазину, категориям, цене, видимость устаревших и отсутствующих товаров, поиск по названию и операции удаления товаров.

## ADDED Requirements

### Requirement: Поиск сохраняет фильтры списка
При заданном параметре `search` система SHALL возвращать только товары, которые удовлетворяют всем остальным переданным фильтрам (`store_code`, `category_id`, `category_ids`, `min_price`, `max_price`, окно видимости устаревших товаров, фильтр наличия) и чьё название содержит подстроку поиска без учёта регистра (включая кириллицу).

#### Scenario: Поиск в одном магазине
- **WHEN** товар «Молоко 1л» есть в магазинах A и B, и клиент запрашивает `GET /api/products?store_code=A&search=молоко`
- **THEN** ответ содержит только запись магазина A

#### Scenario: Поиск не возвращает отсутствующие товары
- **WHEN** товар с подходящим названием имеет `in_stock=false` и клиент не передаёт `include_out_of_stock=true`
- **THEN** товар отсутствует в ответе поиска

#### Scenario: Поиск без учёта регистра кириллицы
- **WHEN** в магазине есть товар «МОЛОКО» и клиент ищет `search=молоко`
- **THEN** товар присутствует в ответе

### Requirement: Некорректные параметры удаления по категориям отклоняются
`DELETE /api/products/clear-by-categories` SHALL возвращать HTTP 400, если `category_ids` не содержит ни одного корректного целого ID, и не удалять никаких товаров.

#### Scenario: Пустой или нечисловой список
- **WHEN** клиент вызывает `DELETE /api/products/clear-by-categories?category_ids=abc`
- **THEN** ответ имеет статус 400 и количество товаров в БД не меняется
