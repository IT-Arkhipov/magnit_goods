# Design

## Context

Мотивация описана в proposal.md. Документация ссылается на код в формате `файл:строка`. После серии lint-фиксов и двух предыдущих изменений этого цикла большинство таких ссылок указывает не туда. Источником истины о поведении служат код и, после архивации предыдущих изменений, `openspec/specs/`.

## Goals / Non-Goals

**Goals:**
- Документы, которые агенты читают первыми (`AGENTS.md`, `CLAUDE.md`), не противоречат коду.
- Формат ссылок, который не устаревает от каждой правки.

**Non-Goals:**
- Переписывание исторических ревью (`docs/code_review_*.md`) и плана `PLAN_FIXES` — кроме отметок о закрытых шагах, которые делают предыдущие изменения.
- Удаление модулей, за которыми стоит возможный будущий сценарий (`NotificationService`, `store_selector.py`, `category_verifier.py`).

## Decisions

### D1. Ссылки `файл:функция` вместо `файл:строка`
Пример: `routes/stores.py:select_store` вместо `stores.py:164`. Имя функции переживает правки внутри файла, а поиск по нему однозначен.
*Альтернатива:* обновить номера строк. Отклонено — они разъедутся снова при следующем коммите.

### D2. Критерий «удалить или пометить»
Удаляется код, на который нет ни одной ссылки в `src/` и за которым не стоит отдельный пользовательский сценарий: приватные хелперы, константы, методы-сеттеры, дублирующая реализация синхронизации категорий. Модули, представляющие самостоятельную функцию (отчёты, Playwright-сканеры), только помечаются в `docs/DEVELOPMENT.md` как неподключённые — решение об их судьбе за владельцем проекта.
Перед удалением каждого имени выполняется `grep -rn "<имя>" src/`. Если найдено использование (например, появилось в предыдущих изменениях), имя не удаляется.

### D3. `AGENTS.md` — единственный источник, `CLAUDE.md` — только дополнения
Исправления вносятся в `AGENTS.md`. Уточнения в `CLAUDE.md`, которые после этого становятся дублем (про миграции), удаляются, как того требует сам `CLAUDE.md`.

## Risks / Trade-offs

- [Удаление функции, которую использует внешний скрипт вне `src/`] → проверить `grep` по всему репозиторию (без каталогов агентов), а не только по `src/`.
- [Документы снова разойдутся с кодом] → правило в `docs/DEVELOPMENT.md`: изменение поведения сопровождается правкой документа в том же изменении (как это уже заложено в tasks предыдущих изменений).
