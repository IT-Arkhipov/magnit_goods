# Spec Delta

## ADDED Requirements

### Requirement: Повтор запросов только при временных ошибках
Сканер SHALL повторять запрос товаров категории (до 3 попыток с паузой) только при сетевых ошибках и ответах 429 и 5xx. При остальных ответах 4xx (например, категория недоступна для типа магазина) категория SHALL пропускаться без повторов и без сброса наличия её товаров.

#### Scenario: Категория недоступна для типа
- **WHEN** API отвечает 400 на запрос товаров категории
- **THEN** выполнен один запрос, категория пропущена, в прогрессе задания — сообщение о недоступности
